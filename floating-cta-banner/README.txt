スマホ/PCで画面に追尾するCTAバナーを表示します。
管理画面から表示位置・サイズ・文言・リンク先・色・表示条件などを設定できます。


== 説明 ==

**Floating CTA Banner** は、サイト訪問者の画面に追尾（sticky/fixed）するコール・トゥ・アクション（CTA）バナーを簡単に追加できるWordPressプラグインです。

=== 主な機能 ===

* 上/下/角の6ポジション対応（PCとモバイルで別設定可能）
* 横幅: auto / full / fixed(px指定) の3モード
* スクロールして指定ピクセルを超えたら表示
* ×ボタンで閉じ、localStorage で再表示を抑止（1日/7日/30日）
* jQuery不要のVanilla JS実装
* 設定がOFFのときはCSS/JSを一切読み込まない
* 管理画面から全項目をGUI操作で設定
* ショートコード対応


== インストール ==

1. プラグインの ZIP を解凍し、`floating-cta-banner` フォルダをそのまま
   `wp-content/plugins/` にアップロードします。
2. WordPress 管理画面の「プラグイン」から「Floating CTA Banner」を有効化します。
3. 「設定 > Floating CTA Banner」を開き、バナーを設定して保存します。
4. 「バナーを有効化」チェックボックスをONにすると、フロントエンドに表示されます。


== 設定項目一覧 ==

=== 基本設定 ===
* **バナーを有効化** – チェックを入れるとバナーが表示されます。

=== レイアウト設定 ===
* **表示位置（PC）** – bottom / top / bottom-left / bottom-right / top-left / top-right
* **表示位置（モバイル）** – PC と別に設定できます
* **横幅モード** – auto（内容幅）/ full（画面幅）/ fixed（px指定）
* **横幅（px）** – widthモードが fixed のときに使用
* **モバイル切替 px** – この幅未満をモバイルとして扱います（0で常にPC）

=== コンテンツ設定 ===
* **メインテキスト** – バナーのメイン文言
* **サブテキスト** – メインテキストの下に表示（任意）
* **ボタン文言** – CTAボタンのラベル（空欄でテキスト全体がリンクに）
* **リンクURL** – ボタン／バナー全体のリンク先
* **リンクターゲット** – _self（同タブ）/ _blank（新タブ）

=== カラー設定 ===
* **背景色** – バナー背景色
* **文字色** – テキスト色
* **ボタン色** – CTAボタンの背景色

=== 表示条件 ===
* **表示対象** – 全ページ / 投稿のみ / 固定ページのみ / 特定ページID
* **ページID（カンマ区切り）** – 表示対象が「特定のページID」の場合に有効
* **カテゴリID（カンマ区切り）** – 投稿のみ対象。指定カテゴリ投稿にのみ表示
* **ログインユーザー非表示** – チェックでログインユーザーにはバナーを非表示
* **スクロール後に表示 (px)** – 指定px以上スクロールしたら表示（0で常時表示）

=== 閉じるボタン設定 ===
* **閉じるボタンを表示** – チェックで右上に × ボタンを表示
* **再表示しない期間** – 閉じた後、次に表示されるまでの日数（1/7/30日）

=== カスタムCSS ===
* バナーデザインを上書きしたい場合に入力（スクリプトタグ不可）


== ショートコード ==

=== 基本使用 ===

投稿・固定ページの本文にショートコードを貼ると、設定に従ったバナーが表示されます。
ショートコードが使われたページでは、「表示条件」の設定に関わらず**必ず**表示されます。

  [floating_cta_banner]

=== 属性で上書き ===

以下の属性を指定すると、管理画面の設定を個別に上書きできます。

  [floating_cta_banner main_text="今すぐ予約" link_url="https://example.com/reserve" button_text="予約はこちら"]

=== 利用可能な属性 ===

| 属性名         | 説明                                      |
|----------------|-------------------------------------------|
| main_text      | メインテキスト                            |
| sub_text       | サブテキスト                              |
| button_text    | ボタン文言                                |
| link_url       | リンクURL                                 |
| link_target    | _self または _blank                       |
| bg_color       | 背景色（例: #1a73e8）                     |
| text_color     | 文字色（例: #ffffff）                     |
| button_color   | ボタン色（例: #ff5722）                   |


== よくある質問 ==

**Q. バナーが表示されません**
A. 「設定 > Floating CTA Banner」を開き、「バナーを有効化」にチェックが入っているか確認してください。また、「表示条件」の設定が現在のページに該当しているか確認してください。

**Q. スマートフォンでだけ非表示にしたい**
A. 現バージョンでは、PCとモバイルで「表示位置」を個別設定できます。モバイルで完全に非表示にする場合は、カスタムCSSに以下を追加してください:
  @media (max-width: 767px) { #fcb-banner { display: none !important; } }

**Q. 閉じたバナーをリセットしたい（テスト用）**
A. ブラウザの開発者ツールを開き、コンソールで `localStorage.removeItem('fcb_dismissed')` を実行してください。

**Q. jQuery は必要ですか？**
A. 不要です。Vanilla JS（jQuery不使用）で実装されています。

== アップグレードの注意 ==

設定はWordPressのデータベースに保存されるため、プラグインを無効化・再有効化しても設定は保持されます。
プラグインを完全に削除する場合は、「設定 > Floating CTA Banner」の設定もデータベースから削除されます
（アンインストール時の自動削除は実装していません。必要に応じて手動で wp_options テーブルから `fcb_settings` を削除してください）。
